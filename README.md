# Super Thinking — Interactive Mental Models Guide

> **Note:** This project is an interactive study guide based on the book *[Super Thinking: The Big Book of Mental Models](https://superthinking.com/)* by **Gabriel Weinberg** and **Lauren McCann**.

## Overview
"Super Thinking" is an interactive, single-page web application that serves as a comprehensive guide to mental models across various disciplines. The application helps users explore concepts like First Principles Thinking, Tragedy of the Commons, and many more, giving them a conceptual toolkit for making better decisions in life and work.

## Features
- **Interactive Diagrams & Simulators**: Includes hands-on elements like an Overfitting vs. Simplicity graph, Conjunction Fallacy Venn diagram, and a Herd Immunity simulator.
- **Categorized Chapters**: Groups mental models into thematic chapters (e.g., "Being Wrong Less", "What Can Go Wrong").
- **Dark & Light Mode**: Built-in theme toggling for reading comfort.
- **Progress Tracking & Quizzes**: Features interactive quizzes at the end of sections and a reading progress bar.
- **Search & Filtering**: Quickly find specific mental models using the top search bar.
- **Responsive Design**: fully usable on both desktop and mobile devices.

## How to Run
Since the application is lightweight and self-contained within a single `index.html` file, no complex setup or build process is required.

1. Navigate to the project directory:
   ```bash
   cd superthinking
   ```
2. Open `index.html` directly in any modern web browser or use a simple HTTP server (e.g. `npx serve`, `python -m http.server`).

## Technologies Used
- **HTML5**: Semantic structure
- **CSS3**: Vanilla CSS for styling, custom CSS variables for theming and dark mode
- **JavaScript**: Vanilla JS for logic, interactivity, and search
- **Canvas API**: For drawing interactive diagrams and charts (e.g., Overfitting diagram, Herd Immunity)
